# cpp-learning

Учебные проекты по C++: от основ до современного C++20/23.

## Структура
Каждый проект или этап — отдельная папка вида `NN-name` (например, `01-hello`, `02-classes`).

## Окружение
- Windows 11, Visual Studio 2026
- Компилятор MSVC, стандарт C++20/23
- Сборка: CMake

## Процесс
Теория — от Grok, код-ревью — Code-Dev.
